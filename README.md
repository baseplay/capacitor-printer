# @baseplay/capacitor-printer

Prints the current Capacitor WebView through the native print dialog (AirPrint / Save as PDF on iOS, PrintManager on Android).

## Install

To use npm

```bash
npm install @baseplay/capacitor-printer
````

To use yarn

```bash
yarn add @baseplay/capacitor-printer
```

Sync native files

```bash
npx cap sync
```
